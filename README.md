# GINpuccin

A Catppuccin Mocha-inspired theme for YASB Reborn.

## Requirements

- [JetBrainsMono Nerd Font](https://www.nerdfonts.com/font-downloads)
- [Komorebi](https://github.com/LGUG2Z/komorebi)

## Install

1. Download or clone this repository.
2. Copy `config.yaml` and `styles.css` into your YASB configuration directory.
3. Replace `YOUR_OPENWEATHER_API_KEY` in `config.yaml` with your own OpenWeather API key.
